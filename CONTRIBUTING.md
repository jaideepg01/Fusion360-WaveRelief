# Contributing

Keep the V1 and V2 script folders independently installable. Include changes to user-visible behavior in the changelog and relevant parameter guide. Validate syntax and profile bounds, then test generation and parameter edits inside Fusion. Record the exact Fusion build, operating system, settings, completion and resulting body properties. A Python syntax check alone cannot validate the Fusion API or loft solver.

Please avoid committing local build logs, personal paths, generated bytecode or machine-specific toolpaths. Include a reproducible example with bug reports. Contributions are provided under this repository’s MIT License.
