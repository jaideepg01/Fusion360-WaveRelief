# Changelog

## Repository release — 2026-10-14

Packages original V1.0.3 and V2.0.0 source together under the MIT License, credited to Gerald Jaideep. Adds unified installation, provenance, original previews, release notes and Autodesk submission preparation. No generator algorithm changes.

## V2.0.0

- Concave channel profile with rounded narrow crests and editable RidgeSharpness.
- 61 sections with adaptive samples at and beside crests.
- Rebuilds built-in styling values from an active V2 design into a new document.
- Retains progress, cancellation and diagnostic logging.

## V1.0.3

Adds visible build progress, cancellation between API operations and diagnostics. Loads the profile helper from its own installation folder. Retains 49 sections × 41 fit points.

## V1.0.2

Uses writable `isLightBulbOn` display properties for sketches and construction planes.

## V1.0.1

Removes the root-component name assignment rejected by Fusion.

The V1.0.1 and V1.0.2 notes are historical records from the supplied documentation; separate releases of those versions are not included.
